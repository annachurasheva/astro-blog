# Ответ: лок-файл и переход на диффы

## Про лок-файл (ваш вопрос)
Да, он работал по локу: установка шла с `--frozen-lockfile` — этот флаг
физически не даёт отклониться от `pnpm-lock.yaml` (при любом расхождении
команда падает с ошибкой, а не молчит).
`package.json` в комплекте — не про зависимости: там меняется ОДНА строка
`repository` (метаданные). Лок от неё не меняется и не должен меняться.
Контроль добавляю в ближайший ход: в `git status --short` обязано НЕ быть
строки про `pnpm-lock.yaml`.

## Про диффы — согласен, так лучше
Zip заставил бы платформу собирать архив — лишний риск отвала.
Диффы четырёх файлов — маленькие, вы их заберёте быстро.
Применение: в GitHub по файлу за цикл (карандаш → правка по диффу → Commit),
либо, если правка по диффу утомит, — приносите дифф мне, я соберу полные
файлы для загрузки.

## Ваша фраза Кодеру (один ход)
Д1: Комплект отдай диффами, не архивом. Выполни ТОЛЬКО:
    git diff -- src/config.ts package.json src/layouts/Head.astro "src/pages/og/[...image].ts"
    и покажи вывод ПОЛНОСТЬЮ, без комментариев.
    Плюс две строки контроля: git status --short
    (в выводе НЕ должно быть pnpm-lock.yaml и node_modules).

## После получения диффов (ваши движения, по одному за цикл)
1. src/config.ts: GitHub → файл → карандаш → внести правки по диффу → Commit.
2. package.json: то же (одна строка repository).
3. src/layouts/Head.astro: то же.
4. src/pages/og/[...image].ts: то же.
5. Сообщить мне хэш последнего коммита — сверяю raw-файлы с диффами.
6. EdgeOne соберёт сам; приёмка вживую: сайт открывается; `/og/index.png`
   открывается; Ctrl+F «apiflash» в коде страницы — 0; вердикт по картинке —
   ваш. Это ТОЧКА СТОП донора, дальше вилки.

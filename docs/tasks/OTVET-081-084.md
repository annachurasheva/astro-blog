# 081–084 · Поправка топологии: журнал ≠ мемориал

## 081 [УРОКИ] · Имена и места (ваша поправка принята)
- memorial-korpech-crimea — это ПРОД мемориала на EdgeOne (туда льётся
  Astro 6.1.5; два package.json в один проект EdgeOne действительно
  не воткнуть). Журнал туда НЕ едет; Qwen App пока НЕ расширяем на него.
- Журнал (учебник «Лечим Astro 6.1.5») живёт отдельно: локально
  poligon-1, репо и домен Pages — revision-of-astro-6-1-5.
  Контур учебника БРОСАЕМ по окончании курса; мемориал продолжается.
- Значит, в очередности 079 шаги 6–8 и 10 читаются с именем
  revision-of-astro-6-1-5 (а не memorial-korpech-crimea).

## 082 [УРОКИ] · Публикация журнала при неопределённых правах
Три маршрута, выбираем по факту прав (ничего не ломаем):
- А: annachurasheva + Actions доступны → наш workflow deploy-pages.yml.
- Б: Actions НЕ дали → Pages из ветки без Actions: собираете dist у себя
  (стенд node 24 тянет vite 6), коммитите dist, Pages → Source:
  «Deploy from branch» → main → /dist.
  Команды в poligon-1: npm ci; npm run build;
  git add -A; git commit -m 'journal: dist'; git push.
- В: зеркало учебника на SC (SC ест статику dist) — независимо от прав
  GitHub; это и есть учебник для РФ-аудитории.
Аккаунт РК — резерв только для маршрута А, если на annachurasheva
Actions не дадут; маршруты Б и В работают без него.

## 083 [ЗЕРКАЛО] · Три строки замены в raznos-journal.ps1
Старая: $Dst     = Join-Path $Head 'memorial-korpech-crimea'
Новая:  $Dst     = Join-Path $Head 'poligon-1'
Старая: Add-Content -LiteralPath $headIgnore -Value 'memorial-korpech-crimea/'
Новая:  Add-Content -LiteralPath $headIgnore -Value 'poligon-1/'
Старая: Invoke-Git @('remote','add','origin','git@github.com:annachurasheva/memorial-korpech-crimea.git')
Новая:  Invoke-Git @('remote','add','origin','git@github.com:annachurasheva/revision-of-astro-6-1-5.git')
Папку memorial-korpech-crimea в astro-blog пока не трогаем: это будущее
локальное тело прода мемориала.

## 084 [АСТРО-БЛОГ·пример] · Разделение контуров подтверждено
Учебник и прод не смешиваются ни в репо, ни в EdgeOne, ни в правах
Кодера. После окончания курса контур учебника архивируется
(репо остаётся как памятник практики, Pages можно выключить),
а мемориал и его вилки идут своей дорогой (донор → тексты → вилки).

## 095 · Два файла перед переносом
1) .gitignore (в корень):
   node_modules/
   dist/
2) .github/workflows/deploy-pages.yml — блок 2 (исправленный под

Рекомендация (не обязательно): один раз npm install у себя → появится

## 096 · Чек-лист переноса (по одному движению)
1. Положить .gitignore и workflow (создать папки .github\workflows).
2. Контрольная сборка на стенде: npm install; npm run build —
   «больной» дашборд должен собраться; dist появится (в коммит не пойдёт).
3. git status --short — глазами: только наши файлы, без node_modules.
4. Шаги 3 из 093: init -b main → add -A → commit → remote → push.
5. GitHub → Settings → Pages: если источник «GitHub Actions» доступен —
   выбрать его и дождаться зелёного прогона. Если Actions на аккаунте
   нет — стоп и мне: включим маршрут Б (dist коммитом, Pages из ветки).
После зелёного Pages: прислать адрес страницы — сверю витрину.
```

```yaml
# ФАЙЛ: revision-of-astro-6-1-5/.github/workflows/deploy-pages.yml
name: deploy-pages
on:
  push:
    branches: [main]
  workflow_dispatch:
permissions:
  contents: read
  pages: write
  id-token: write
concurrency:
  group: pages
  cancel-in-progress: true
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - run: npm install --no-audit --no-fund
      - run: npm run build
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v3
        with:
          path: dist
  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

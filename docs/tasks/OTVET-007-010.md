## 008 · Что дозакрыть (одна правка И4)
- В config.ts остались ЗАГЛУШКИ шаблона: `googleAnalyticsID: 'G-XXXXXXXXXX'`
  и `twitterID: '@yourtwitter'`. Заглушка GA — не безвредна: Head.astro
  видит непустой ID и тащит чужой скрипт статистики. Обе в пустые строки.
- В package.json Кодер самовольно поднял версию 1.0.0 → 1.0.1 (не просили —
  вернуть), а строку `repository` на ваш репозиторий я в диффах так и не
  увидел — поставить явно.

## 009 · Почему вам было непонятно — и как теперь
Диффы приезжали КУСКАМИ (раунд 1, раунд 2) — вручную их складывать нельзя,
это моя ошибка приёма. Новый способ: один накопительный дифф-файл и одна
команда `git apply` у вас на ПК. Карандаш в GitHub больше не нужен.

Фразы Кодеру (по одной):
И4: Правки без сборки: в src/config.ts значения
    googleAnalyticsID: '' и twitterID: ''; в package.json version вернуть
    на 1.0.0 и repository поставить
    "repository": "https://github.com/annachurasheva/astro-blog".
    Больше ничего не трогать. Ответь OK.
И5: Отдай ОДИН накопительный дифф против HEAD, целиком одним файлом:
    git diff -- src/config.ts package.json src/layouts/Head.astro "src/pages/og/[...image].ts"
    Файл назови final.patch и отдай на скачивание. Ничего сверх.

## 010 · Ваши движения после получения final.patch (по одному)
1. Положить final.patch в C:\astro-blog\ (переименовать при нужде).
2. PowerShell из C:\astro-blog:
   git apply final.patch
   git status --short
   (жду четыре строки M по нашим файлам; пришлите вывод)
3. Д0: git ls-files src/content/posts — пришлите список (сверка скрипта).
4. Д1: сохранить clean-posts.ps1 в C:\astro-blog\scripts\ (кнопка
   «Сохранить как» из Edge по ссылке из ответа про clean-posts).
5. Д2: .\scripts\clean-posts.ps1 — жду «Осталось постов: 0».
6. Д3: git add -A src package.json scripts
   git commit -m "donor: identity, og-local, clean template posts"
   git push
7. Пришлите хэш — raw-сверка, затем живой деплой и приёмка → ТОЧКА СТО

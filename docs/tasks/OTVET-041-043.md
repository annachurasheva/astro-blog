# 041–043 · SSH понятен, origin догнан, добро на переезд

## 041 · Про два remote
Понял: origin (SSH) и origin2 (HTTPS) — ОДИН репозиторий на GitHub;
origin2 остался от эпохи токенов, после их отзыва доверенный маршрут — SSH.
Сейчас ничего не трогаем; после ТОЧКИ СТОП, отдельным маленьким шагом,
можно удалить origin2 (git remote remove origin2), чтобы push никогда не
путался. До СТОПа — не трогать.

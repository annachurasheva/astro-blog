# Ответ: это не «полез править», это шум инструментов

## Что это
Содержимое диффа — машинный JSON карты исходников (`.d.ts.map`).
Такие файлы пересоздают сами инструменты (TypeScript/pnpm) при установке
и проверках. Это НЕ ручная правка Кодера и НЕ осмысленное изменение.
Ваше чутьё верно держит границу: в node_modules вообще нечего читать.

## Почему это не страшно
- В git эти файлы НЕ отслеживаются: `.gitignore` содержит `node_modules/`.
  Критерий чистоты — только `git status --short`, а не дифф-панель
  платформы. Панель показывает файловую систему, а не репозиторий.
- В комплект передачи (4 файла) этому попасть невозможно, если Кодер
  не положит туда node_modules руками — а это запрещено.

## Что меняем в правилах (барьер от траты ресурса)
node_modules для Кодера — «камин»: не читать, не диффить, не описывать
в ответах, не «улучшать», не возвращать. Единственный вопрос к нему —
строка из `git status --short`.

# 035–037 · emails в типе, пустая строка lang, пост-пустышка

## 035 · Причина ошибки и две правки
Тип ThemeConfig в src/types/index.d.ts не знает поля `emails` в site —
а я в чистом config.ts (025) его оставил. Моя несостыковка: вместе с
emails надо было расширить тип. Лечится одной строкой в типе.
Заодно убираю строку 18 в Head.astro (`const lang = ...`) — она даёт
warning «never read»: после удаления Apiflash она действительно не нужна.

Правка 1 — src/types/index.d.ts, в блоке site после строки favicon:
Было:
    base: string
    favicon: string
  }
Стало:
    base: string
    favicon: string
    emails?: string[]
  }

Правка 2 — src/layouts/Head.astro: удалить строку 18 целиком:
    const lang = currentLang === defaultLocale ? '' : `${currentLang}/`

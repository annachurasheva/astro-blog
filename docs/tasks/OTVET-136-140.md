Берите в каждой консоли вариант «HTML meta tag» (мета-тег), НЕ DNS TXT
и НЕ файл-загрузку: шаблон сам рисует мета-теги из config.
Нужные консоли: Yandex Webmaster (РФ), Google Search Console (зарубежь),
Baidu Webmaster (китайский контур — намеренно), Bing — по желанию.
Куда класть: src/config.ts → seo.verification → google / yandex /
baidu / bing (длинные строки content).
Там же, тем же коммитом: site.url → https://memorial-korpech-crimea.edgeone.dev
(иначе canonical/OG/sitemap смотрят на тестовый домен).
Конструкт: git add src/config.ts; commit -m "fix: verification meta, site.url свой (139)"; push.

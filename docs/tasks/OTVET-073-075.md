# 073–075 [ЗЕРКАЛО] · Ревизия git-isolated-sc.ps1 под нашу реальность

Файл прочитан целиком через browse (raw закрыт капчей — присылать
файлом не нужно). Вердикт: скрипт качественный (изоляция git, идемпотентность,
нет автопуша, окно остаётся). Коррекции НУЖНЫ — восемь, все под реальность
«GitHub могут отключить, SC — тихая гавань».

## 073 · Список коррекций (FIX-1…FIX-8, помечены в коде v2)
- FIX-1 Блокоустойчивость: проверка GitHub больше НЕ валит скрипт.
  Недоступен — жёлтое предупреждение «работаем через SC».
  Обязательной становится проверка SC (ls-remote sc): нет SC — стоп.
- FIX-2 Второй remote `sc` = ssh://ssh.sourcecraft.dev/mem-2026/astro-blog.git
  (идемпотентно: добавить/выровнять). Зеркало — это он.
- FIX-3 keyscan github.com и ssh.sourcecraft.dev в проектный known_hosts
  (иначе первый коннект умрёт на проверке ключа хоста).
- FIX-4 .ssh УЖЕ отслеживается в репо (это пункт К1 ревизии EdgeOne):
  скрипт делает git rm -r --cached .ssh; коммит — ваш, вручную.
- FIX-5 В изолированном global-config нет идентичности (кастрированная W10):
  скрипт сам ставит user.name/user.email (Anna Churasheva / gmail),
  иначе коммиты не пойдут.
- FIX-6 SourceCraft CLI теперь НЕОБЯЗАТЕЛЕН: ошибка установки/скачивания —
  предупреждение, а не смерть. Зеркало ходит чистым git+SSH без src.
- FIX-7 fetch: origin только если GitHub жив; sc — всегда (падение = стоп).
- FIX-8 Зеркалирование: ключ -PushMirror пушит main + рабочую ветку + теги
  в sc; без ключа скрипт только печатает команды зеркала (человек решает).

## 074 · Про необходимость SourceCraft CLI (src) — позиция
src = СЛОЙ УДОБСТВА портала: аутентификация IAM/PAT, credential helper,
issues, опенкод-AI. Для ЗЕРКАЛА он не нужен: достаточно git + SSH-ключа
и remote `sc`. Поэтому в v2 установка src не может убить окружение,
а всё жизненно важное (fetch/push/зеркало) работает без него.
setup-git от src оставляем: пригодится, если захотите HTTPS-маршрут
на SC как запасной при полном отвале SSH.

## 075 · Как вводить (ваши движения, по одному)
1. Сохранить блок 2 как C:\astro-blog\scripts\git-isolated-sc.ps1
   (перезаписать старый; копия на SC обновится вашим коммитом).
2. Запустить: pwsh -NoProfile -File scripts\git-isolated-sc.ps1
   (первый раз без ключа — посмотреть вывод; окно остаётся открытым).
3. В том же окне: git push sc main main-qwen3-coder-plus-v01
   и git push sc --tags — первое зеркало на SC.
4. Дальше зеркалирование тем же окном или ключом -PushMirror.
GitHub пока жив — остаётся origin; отвалится — ничего не ломаем:
скрипт сам перейдёт на SC при следующем запуске.

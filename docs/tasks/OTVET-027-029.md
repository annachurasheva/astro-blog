## 028 · Последняя правка во всём доноре — одна строка в Head.astro
Сейчас: `const pageImage = `${base}/og/${postSlug ?? 'index'}.png``
Надо:   `const pageImage = new URL(`${base}/og/${postSlug ?? 'index'}.png`, Astro.url.origin)`
Зачем: og:image обязан быть абсолютным адресом, иначе соцсети не
подтянут превью при шеринге ссылки.
Команды:
git add src/layouts/Head.astro
git commit -m "donor: absolute og:image"
git push

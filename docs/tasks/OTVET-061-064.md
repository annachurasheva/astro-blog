# 061–064 · Журнал-пробник = работа над ошибками по ревизии

## 061 · Предложение принято; лимит 3Мб — вписываю в конструкцию
Да, «работа над ошибками по ревизии EdgeOne AI» — идеальный пробник:
реальный кейс, две ревизии, живые фиксы — именно это и есть пособие.
Ограничения под 3Мб:
- в журнале НЕТ бинарников: скриншоты/картинки — только ссылками;
- данные — текст; потолок data-файлов ~200КБ;
- контроль размера на каждый пуш (папка репо < 2МБ);
- превысили порог — старый этап уходит в docs/archive, из data удаляется.
Про 22 ноду: каркас дашборда (vite+react+tailwind) собирается и на 22,
и на 24 — конфликта со стендом нет, журнал ведь отдельный репо.

индексы (Google/Яндекс/Bing) и коммиты GitHub идут в пособие
материалом (как вы и сказали).

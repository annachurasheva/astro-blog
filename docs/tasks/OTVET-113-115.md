## 114 · Конструкт коммита (шаблон 3.5, приучаемся к порядку)
Каждая моя инструкция дальше содержит такой конструкт:
1) Где: cd <папка> и ветка: git switch <ветка>
2) Что: git add <ТОЧНЫЙ список файлов>   (никогда git add .)
3) Сообщение: git commit -m "<тип>: <простыми словами> (<номер>)"
   типы: docs (бумаги), fix (починка), chore (хозяйство), feat (новое)
4) Куда: git push origin <ветка>
5) Проверка: git log -1 --oneline   (показать мне последнюю строку)

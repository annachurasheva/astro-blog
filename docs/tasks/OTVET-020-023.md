## 023 · Команды «бак + перезапись main» (новый стиль git), после пуша 022
git fetch origin
git branch main-bak-2026-09-04 origin/main
git push origin main-bak-2026-09-04

git reset --hard origin/main-qwen3-coder-plus-v01

По строкам: скачать свежее; создать ветку-бак от текущего main;
опубликовать бак (EdgeOne деплоит только main, бак безопасен);
встать на main; положить main ровно на рабочую ветку;
силовой пуш с предохранителем (упрётся, если в main кто-то писал мимо вас);
вернуться на рабочую ветку.

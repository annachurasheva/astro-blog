## ОТЧЕТ О ВОЗМОЖНОСТИ ФОРМИРОВАНИЯ RSS-ЛЕНТЫ ИЗ ПОСТОВ (ПУБЛИКАЦИЙ)

### 1. ОБЩИЕ СВЕДЕНИЯ

Объект анализа: Шаблон блога на Astro (репозиторий:`https://github.com/annachurasheva/astro-b-v2.git`, тема Retypeset)
Цель:Оценка технической возможности формирования RSS-ленты из публикаций
Текущее состояние:В шаблонеполностью реализованасистема генерации RSS и Atom лент с расширенным функционалом.

---

### 2. АРХИТЕКТУРА СИСТЕМЫ RSS/ATOM ЛЕНТ

#### 2.1. Структура файлов

| Компонент         | Путь                             | Назначение                        |
| ----------------- | -------------------------------- | --------------------------------- |
| Генератор RSS     | /src/pages/[...lang]/rss.xml.ts  | Создание RSS 2.0 ленты            |
| Генератор Atom    | /src/pages/[...lang]/atom.xml.ts | Создание Atom 1.0 ленты           |
| Утилита генерации | /src/utils/feed.ts               | Основная логика формирования лент |
| Стили XSLT        | /public/feeds/rss-style.xsl      | Визуальное оформление RSS         |
| Стили XSLT        | /public/feeds/atom-style.xsl     | Визуальное оформление Atom        |

#### 2.2. Точки доступа

После сборки проекта ленты доступны по адресам:

- RSS:`https://ваш-сайт.com/rss.xml`(или`/lang/rss.xml`для мультиязычных версий)
- Atom:`https://ваш-сайт.com/atom.xml`(или`/lang/atom.xml`для мультиязычных версий)

---

### 3. ФУНКЦИОНАЛЬНЫЕ ВОЗМОЖНОСТИ

#### 3.1. Автоматическая генерация контента

| Функция                 | Описание                                         |
| ----------------------- | ------------------------------------------------ |
| Фильтрация постов       | Исключение черновиков (draft: true)              |
| Языковая сегментация    | Отдельные ленты для каждого языка                |
| Сортировка              | По дате публикации (новые первые)                |
| Лимитирование           | Максимум 25 последних постов в ленте             |
| Оптимизация изображений | Конвертация относительных путей в абсолютные URL |
| Sanitization            | Очистка HTML-контента от небезопасных тегов      |
| Извлечение описания     | Автогенерация description из контента поста      |

#### 3.2. Поддерживаемые форматы

| Формат | Стандарт | Метод генерации |
| ------ | -------- | --------------- |
| RSS    | RSS 2.0  | feed.rss2()     |
| Atom   | Atom 1.0 | feed.atom1()    |

#### 3.3. Расширенные возможности

1. XSLT-стилизация:Встроенные таблицы стилей для красивого отображения в браузере
2. Folo-верификация:Поддержка расширения`folo_challenge`для децентрализованной верификации
3. Мультиязычность:Автоматическое определение языка ленты на основе URL
4. Кэширование:Использование memoization для оптимизации обработки изображений

### 5. ТЕХНИЧЕСКИЕ ОСОБЕННОСТИ

#### 5.1. Зависимости

В`package.json`указана библиотека:

```
"feed": "^5.2.0"
```

#### 5.2. Обработка изображений

Система автоматически:

1. Находит все изображения в директории`/src/content/posts/_images/`
2. Оптимизирует их через`getImage()`Astro
3. Преобразует относительные пути в абсолютные URL
4. Внедряет в контент ленты

#### 5.3. Интеграция с Head

В`/src/layouts/Head.astro`автоматически добавляется:

```
<link rel="alternate" href="/rss.xml" type="application/rss+xml" title="RSS Feed" />
```

### 6. ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ

#### Шаг 1: Проверка конфигурации

Убедитесь, что в`/src/config.ts`корректно заполнены:

- `site.url`— домен вашего сайта
- `site.author`— имя автора
- `site.base`— базовый путь (если сайт в поддиректории)

#### Шаг 2: Настройка футера (опционально)

Выберите предпочтительный формат в`/src/config.ts`:

```
url: '/rss.xml'  // для RSS
// или
url: '/atom.xml' // для Atom
```

#### Шаг 3: Сборка проекта

```
npm run build
```

#### Шаг 4: Проверка результата

Ленты будут доступны по адресам:

- `https://ваш-сайт.com/rss.xml`
- `https://ваш-сайт.com/atom.xml`

Для мультиязычного сайта:

- `https://ваш-сайт.com/en/rss.xml`
- `https://ваш-сайт.com/zh/rss.xml`

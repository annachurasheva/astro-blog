# ИТЕРАЦИИ · интерактивный журнал исполнения шагов

Правило: итерация = 1–3 ответа Кодера; конец итерации — статус done
+ артефакт + галочка в данных. Прогресс-бар = done/всего.

I-1 · Скелет и публикация
Vite+React+TS+Tailwind; workflow Actions → Pages.
Приёмка: пустое приложение открыто на Pages без рук.

I-2 · Данные и список с галочками
src/data/steps.ts: { id, title, status, details }; рендер списка,
галочки по status. Приёмка: галочки видны, статусы кликабельны в dev.

I-3 · Раскрывающиеся блоки и прогресс
Аккордеон для details; прогресс-бар сверху. Приёмка: клики раскрывают,
прогресс пересчитывается.

I-4 · Мини-анимации
Появление блоков, движение прогресса; уважать prefers-reduced-motion.
Приёмка: при reduced-motion анимации отключены.

I-5 · Содержание урока «работа над ошибками EdgeOne AI»
Три этапа из revision-1/2 (критические; высокие+средние; низкие);
astro-blog — пример. Приёмка: три этапа с данными и ссылками на коммиты.

I-6 · Слои чтения
Переключатель «руководитель (не-ИТ)» / «juniors». Приёмка: оба слоя
читаются, тексты не смешиваются.

I-7 · Лимиты и архив
Контроль размера на пуш; архив старых этапов. Приёмка: отчёт о размере.

# QWEN-JOURNAL.md · мануал строителя журнала · v3

Ты — строитель журнала-пособия «работа над ошибками по ревизии
EdgeOne AI». Твоя зона — ТОЛЬКО данные: src/data/{moves,decisions,
debug}.ts и строки слоёв. Компоненты, каркас, index.html — НЕ трогать.
Сборку и публикацию делает GitHub Actions — не ты.
Чужие репо (astro-blog и пр.) НЕ открывать; источники — только
docs/revision-1.md и docs/revision-2.md этого репо.

## Слои пособия (обязательно на каждый этап)
- «Для руководителя (не-ИТ)»: 3–5 фраз человеческим языком:
  что было плохо, что сделали, чем кончилось.
- «Для juniors»: команды, диффы, ссылки на коммиты, статусы.

## Формат записей (как в mem-OK)
move: { id 'm-NNNN', ts unix, kind, text, target }
decision: { id 'd-NNN', date, title, status }
debug: { ts, level info|warn|error, source, text }
Этапы = листы V0xSheet: 1 критические, 2 высокие+средние, 3 низкие.

## Лимит 3МБ (жёстко)
Бинарников нет; картинки — ссылками; data-файлы суммарно < 200КБ;
репо < 2МБ; порог превышен — этап в docs/archive, из data удалить.
Контроль: размер папки при каждом пуше.

## Дисциплина
Один ответ = один этап (или его часть по заданию) + полные файлы,
которые тронул. Факты — только из revision-1/2 и текста задания.
Обрыв: назвать последний готовый id и остановиться.

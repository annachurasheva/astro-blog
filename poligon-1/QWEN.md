# QWEN.md · полигон «Интерактивные уроки» · v4

Предмет: продукт «уроки» — интерактивный журнал исполнения шагов:
прогресс, галочки, раскрывающиеся блоки, мини-анимации.
Стек (ремонтный): Vite + React + TypeScript + Tailwind.

## Статус репо
Это ПЕСОЧНИЦА. Разрешено: dev, build, правки компонентов, эксперименты.
Запрещено: открывать иные репо; контекст свыше 3МБ; бинарники в репо;
вложенные дашборды («дашборд в дашборде»).
astro-blog — ТОЛЬКО пример-кейс для содержания уроков
(источники: docs/revision-1.md, docs/revision-2.md); сам astro-blog не трогать.

## Публикация
GitHub Actions собирает и деплоит Pages при каждом пуше.
Ты НЕ публикуешь вручную и НЕ просишь владельца «опубликовать».
Твой артефакт — файлы; переносит в репо владелец.

## Сессии и анти-фриз
Не более 6 ответов за сессию; после 5-го готовишь handover.md:
последний завершённый шаг, следующий шаг, последние id.
Обрыв/квота: назвать последний id и остановиться.
Контекст читай с диска; не пересказывай; не повторяй выданное.
Один ответ = один артефакт.

## Устройство журнала
Данные ОТДЕЛЕНЫ от компонентов: src/data/*.ts растут, компоненты редки.
Итерации и статусы — docs/ITERATIONS.md (todo/doing/done).
Прогресс = доля done-шагов. Формат записей — как в mem-OK,
но без вложенности и без бинарников.
Лимит: репо < 2МБ, data суммарно < 200КБ; порог — архив в docs/archive.

## Слои пособия
«Для руководителя (не-ИТ)»: 3–5 фраз на этап.
«Для juniors»: команды, диффы, ссылки на коммиты.

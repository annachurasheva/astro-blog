### 5. ТРЕБУЕМЫЕ ДЕЙСТВИЯ ПОЛЬЗОВАТЕЛЯ

#### 5.1. Настройка Giscus (комментарии)

1. Перейти на[https://giscus.app/ru](https://giscus.app/ru)
2. Указать репозиторий GitHub для хранения комментариев
3. Скопировать параметры в`src/config.ts`:
    - `repo`
    - `repoId`
    - `category`
    - `categoryId`

#### 5.2. Добавление контента

- Добавить посты в папку`/src/content/posts/`
- Предоставить текст для заглавной страницы (ожидаем от пользователя)

#### 5.3. Локальное тестирование (Windows + PowerShell 7.6.5)

```
cd C:\astro-b-v2
.\scripts\run-edge-vk-test_v03.ps1
```
